# House Prices Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on analysing house prices using Python. The main aim is to understand how different features affect house prices through data analysis and visualization.

## Dataset
- Source: Kaggle – House Prices: Advanced Regression Techniques
- Rows: 1460
- Columns: 81

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Work Performed
1. Loaded and explored the dataset.
2. Checked missing values and duplicate records.
3. Analysed numerical and categorical data.
4. Created graphs and visualizations.
5. Detected outliers using the IQR method.
6. Handled missing values.
7. Created a final EDA dashboard.

## Conclusion
This project helped me understand data analysis, data cleaning, outlier detection and data visualization using Python.
